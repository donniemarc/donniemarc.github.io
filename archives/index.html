PlotVault PDM 更新日志

v0.1.0 (2026-01-XX)

新功能

  • 初始版本发布
  • 文件夹树 + 文件列表
  • 文件上传（支持拖拽）、下载、删除、重命名、移动
  • 版本管理：同名文件重复上传自动成为新版本
  • 文件名搜索
  • API Token 访问控制

支持的文件格式

  • 2D 图纸：DWG、DXF
  • 3D 模型：STEP/STP、IGES/IGS、STL
  • 文档：PDF
  • 其他：图片、文本文件

技术架构

  • 后端：Rust + Axum + PostgreSQL
  • 客户端：Tauri 2 + Vue 3 + Three.js
  • 部署：Docker Compose

预览功能

  • DWG：服务端 libredwg 转 DXF → 客户端 Three.js 渲染
  • DXF：客户端直接渲染
  • STEP/IGES：客户端 occt-import-js（OpenCascade WASM）直接解析
  • STL：Three.js 直接渲染
  • PDF：pdf.js 渲染

后续计划

  • 缩略图（STL/STEP 服务端渲染小图）
  • 版本对比 / DWG 导出 PDF
  • 批量打包下载（zip）
  • 标签 / 分类 / 全文检索
  • 审计日志、多用户权限
