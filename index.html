PlotVault PDM - 轻量级自建图纸文档管理系统

PlotVault PDM

让你的模型和设计文件不再散落各处。

PlotVault 是一个轻量级自建图纸文档管理系统，专为 3D 打印爱好者和设计师打造。它让每个文件都有版本历史，同名上传自动归档旧版；图纸直接存在你 NAS 的真实目录里，不用打开软件也能浏览备份。

为什么选择 PlotVault？

  • 版本管理：同名文件重复上传自动成为新版本，可查看历史、下载任意旧版、附版本备注
  • 多格式预览：支持 DWG/DXF/STEP/IGES/STL/PDF 等多种格式的在线预览
  • 轻量部署：Docker Compose 一键部署，后端镜像仅约 20MB
  • 数据安全：图纸文件以真实目录存储在磁盘上，备份就是拷贝目录
  • 桌面客户端：基于 Tauri 的原生桌面客户端，启动快、体积小

技术亮点

组件 技术栈 特点
后端 Rust + Axum + PostgreSQL 单个静态二进制，7x24 常驻零负担
客户端 Tauri 2 + Vue 3 + Three.js 原生窗口、安装包小、启动快
存储 真实目录 + PostgreSQL 目录即数据，备份就是拷贝目录

快速开始

支持的文件格式

格式 预览方案
DWG 服务端 libredwg 转 DXF → 客户端 Three.js 渲染
DXF 客户端直接渲染（LINE/多段线/圆/圆弧/椭圆/样条/文字标注）
STEP/STP/IGES/IGS 客户端 occt-import-js（OpenCascade WASM）直接解析
STL Three.js 直接渲染
PDF pdf.js 渲染
