使用说明

PlotVault PDM 使用说明

本文档介绍如何使用 PlotVault PDM 桌面客户端来管理你的图纸文件。

客户端安装

Windows 客户端构建

在一台 Windows PC 上构建一次即可（安装包可分发给其他机器）。

前置要求：

  • Rust（MSVC 工具链 + Visual Studio Build Tools C++ 工作负载）
  • Node.js 18+
  • WebView2 运行时（Win10/11 一般自带）

构建步骤：

产物位于 client/src-tauri/target/release/bundle/。

开发调试：

首次连接

  1. 启动客户端
  2. 点击右上角 设置 按钮
  3. 填入服务器地址：http://<主机IP>:8642
  4. 填入 API Token（与服务端配置的 token 一致）
  5. 点击 测试连接 确认连接成功
  6. 点击 保存

基础操作

文件夹树

左侧显示文件夹树结构，点击文件夹可展开或收起子目录。

文件列表

右侧显示当前文件夹中的文件列表，包括：

  • 文件名
  • 文件大小
  • 最后修改时间
  • 版本号（如有多个版本）

文件操作

  • 上传：点击右上角「上传」按钮，或直接把文件拖进窗口
  • 下载：选中文件，点击「下载」按钮
  • 删除：选中文件，点击「删除」按钮
  • 重命名：选中文件，点击「重命名」按钮
  • 移动：选中文件，点击「移动」按钮，选择目标文件夹

版本管理

PlotVault 的核心功能之一是版本管理。

上传新版本

同目录同名文件上传会自动作为新版本。旧版本不会被删除，而是归档到版本历史中。

查看版本历史

  1. 选中文件
  2. 点击「版本」按钮
  3. 查看所有版本列表
  4. 可以下载任意旧版本
  5. 上传新版本时可以附带备注

版本备注

每次上传新版本时，可以添加备注说明修改内容，方便日后查阅。

文件预览

PlotVault 支持多种文件格式的在线预览：

格式 预览方式
DWG/DXF Three.js 2D 渲染
STEP/IGES OpenCascade WASM 3D 渲染
STL Three.js 3D 渲染
PDF pdf.js 渲染
图片 内建图片查看器
文本 内建文本查看器

预览操作

  • 缩放：鼠标滚轮
  • 旋转（3D 文件）：鼠标左键拖拽
  • 平移：鼠标右键拖拽
  • 关闭预览：点击右上角关闭按钮

搜索功能

在文件列表上方的搜索框中输入关键词，可以快速查找文件。

快捷键

快捷键 功能
Ctrl+U 上传文件
Ctrl+D 下载文件
Delete 删除文件
F2 重命名文件
Ctrl+F 搜索文件
