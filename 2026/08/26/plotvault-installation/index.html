PlotVault PDM 安装部署指南

发表于2026-08-26|更新于2026-08-27|PlotVault
|浏览量:

本文档介绍如何部署 PlotVault PDM 后端服务。PlotVault 支持多种部署方式，推荐使用 Docker Compose 进行一键部署。

前置要求

  • Docker 和 Docker Compose
  • 至少 1GB 的磁盘空间
  • 网络连接（用于拉取镜像）

方式 A：Docker Compose（推荐）

这是最简单的部署方式，只需几步即可完成。

步骤 1：准备配置文件

从仓库复制 docker-compose.yml 文件到你的部署目录：

步骤 2：配置环境变量

编辑 docker-compose.yml，替换所有 <...> 占位符：

占位符 说明 示例值
<DOCKERHUB_USER> Docker Hub 用户名 donniemarc
<数据库密码> PostgreSQL 数据库密码 your_secure_password
<API_TOKEN> 客户端连接用的访问令牌 your_api_token
<HOST_PORT> 对外端口 8642
<DATA_HOST_PATH> 图纸数据宿主目录 /home/user/plotvault/data
<CONFIG_HOST_PATH> 软件缓存宿主目录 /home/user/plotvault/config
<PGDATA_HOST_PATH> 数据库数据宿主目录 /home/user/plotvault/pgdata

步骤 3：启动服务

启动后将运行三个容器：

  • db - PostgreSQL 18（存储元数据）
  • plotvault-pdm - 后端 API，端口 8642
  • converter（可选）- STEP/IGES 服务端转换，端口 8000

常见问题

DWG 预览报错「dwg2dxf not available」？

说明容器内没有 dwg2dxf（本机裸跑二进制时常见，Docker 镜像会从源码编译 libredwg）。请用 Docker 部署；转换只在首次预览时执行并缓存到 CONFIG_DIR/dxf_cache。

如何备份？

备份图纸拷贝 data/ 目录（library 真实目录 + blobs 归档）即可；建议一并备份 pgdata/ 卷（目录结构、版本备注等元数据，丢了不影响图纸文件本身）。

数据库连不上？

确认 compose 中 db 容器先启动且健康（pg_isready），DATABASE_URL 的用户/密码/库名与 POSTGRES_* 一致。
